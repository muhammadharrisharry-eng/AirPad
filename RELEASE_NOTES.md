## AirPad

Use your phone as a wireless touchpad and keyboard for your laptop. Free, open source, no cloud, no account.

**Windows:** download `AirPad.exe` below, run it, allow the firewall prompt for private networks, then scan the QR code on the pairing page with your phone (same WiFi).

**Mac / Linux:** run from source, see the README. Mac and Linux are untested so far.

### Highlights
- Touchpad with momentum scroll, three-finger swipes, Enter and Speed buttons
- Live screen view with tap-to-click
- Phone keyboard, shortcuts, your own shortcuts and snippets, open an app by name
- AirDrop-style file transfer, clipboard, presenter keys, power controls
- PIN protected, local network only

### Known limits
- The exe is not code signed, so Windows may say "Unknown publisher" (More info, then Run anyway).
- Early release. Please report problems in Issues with your phone, browser and Windows version.

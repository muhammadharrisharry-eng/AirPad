Download AirPad.exe, open it, and allow the Windows Firewall prompt for private networks.

Everything you need

Real touchpad

Tap, right-click, drag, momentum scroll and three-finger swipes.

Live screen

See your laptop on the phone and tap to click.

Keyboard and shortcuts

Type from your phone, send media keys, presenter controls and shortcuts.

Clipboard and files

AirDrop-style: send photos from your phone, pick up files from your laptop.

Power controls

Lock, sleep, restart or shut down with a safe press-and-hold.

Private by design

PIN protected, local network only, public internet addresses are rejected.

Questions

Is it free?

Yes. AirPad is open source under the MIT license. No subscription, no ads.

Does it need internet?

No. Your laptop and phone only need to be on the same WiFi. Your keystrokes and screen never leave your network.

My phone cannot open the page

Open http://LAPTOP-IP:8765/health on the phone. Try every address on the pairing page, turn off VPNs and mobile data. Guest WiFi blocks this, so use your phone hotspot instead.

Mac and Linux?

Run it from source: pip install -r requirements.txt then python server.py. macOS needs Accessibility permission. Linux needs X11.

Windows says "Unknown publisher"

The app is not code signed yet. Choose More info, then Run anyway. The exe is built by GitHub Actions from the public source.
